# Modelos FreeCAD

Arquivos `.FCStd` com as peças e montagens do projeto.

| Arquivo | Descrição |
| ------- | --------- |
| `bastidor para caixa-guia.FCStd` | Bastidor de sustentação da caixa-guia |
| `caixa-guia para tecido.FCStd` | Caixa-guia por onde passa o tecido |
| `haste guia para estrutura de movimentação vertical.FCStd` | Haste de guia da estrutura de movimentação vertical |
| `suporte motor de lixa.FCStd` | Suporte do motor de lixa |

## Como abrir

1. Abra o FreeCAD (versão 0.20 ou superior).
2. `Arquivo > Abrir` e selecione o `.FCStd`.

## Observações

- Arquivos de backup (`*.FCBak`) não são versionados.
- Salve sempre com nome descritivo e versão, por exemplo `capa-motor-v2.FCStd`.

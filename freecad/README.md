## Como abrir

1. Abra o FreeCAD (versão 0.20 ou superior).
2. `Arquivo > Abrir` e selecione o `.FCStd`.
3. Para ver a montagem completa, abra o arquivo `montagem*.FCStd`.

## Observações

- Arquivos de backup (`*.FCBak`) não são versionados.
- Salve sempre com nome descritivo e versão, por exemplo `capa-motor-v2.FCStd`.
